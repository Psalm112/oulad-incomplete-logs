# Data (not included)

Download the Open University Learning Analytics Dataset (OULAD) and unzip the CSV files here:

- https://analyse.kmi.open.ac.uk/open_dataset
- or the UCI copy: https://archive.ics.uci.edu/dataset/349/open+university+learning+analytics+dataset

Expected files: `studentInfo.csv`, `studentRegistration.csv`, `studentVle.csv`, `vle.csv`,
`assessments.csv`, `studentAssessment.csv`, `courses.csv`.

dataset. *Scientific Data* 4, 170171 (2017).
